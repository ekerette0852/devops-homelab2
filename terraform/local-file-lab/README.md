# Terraform Local File Lab

## Objective

Learn Terraform fundamentals by creatint and managing resources through Infrastructure as code.

## Skills Demonstrated

- Terraform installation
- Provider configuration
- Resource creation
- State management
- Terraform plan
- Terraform apply

## Commands Used

terraform init

terraform plan

terraform apply

## Verification

Terraform successfully created:

homelab.txt

Terraform state file:

terraform.tfstate
