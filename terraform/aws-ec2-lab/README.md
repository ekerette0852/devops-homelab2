# Terraform AWS EC2 Lab

## Objective
Provision an EC2 instance on AWS using Terraform.

## Technologies
- Terraform
- AWS EC2
- AWS CLI
- IAM

## Commands Used

terraform init
terraform plan
terraform apply
terraform show
terraform destroy

## Result

Successfully provisioned and destroyed a t3.micro EC2 instance using Infrastructure as Code.

## Skills Demonstrated

- Infrastructure as Code
- AWS IAM
- AWS CLI
- EC2 Management
- Terraform State Management
